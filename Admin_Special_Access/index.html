UTP VCR

Secure Document Verification & Code Requisition

The UTP Vendor Code Requisition (VCR) website functions as a secure request and approval gateway. Administrators access the platform to strictly review and verify customer applications and sensitive financial documents before issuing a Vendor Code, maintaining high standards of security and compliance.

The Verification Process Flow

Ensuring authenticity of identity and financial compliance.

Customer Submission

Applicants submit their application forms and upload all required documents (IC, bank statements, etc.) via the segregated public portal.

Document Review

KYC6 Administrators review documents, conducting both manual and automated verification checks on identity data.

Final Requisition

Master Admin verifies all documents, and initiates the vendor code requisition process based on successful background checks.

Administrative Responsibilities

KYC6 Admin

Performs background checks to verify the user's compliance record is clean.

AE Admin

Serves purely as a referral link for External Appointments; monitors progress but does not perform primary verification.

Master Admin

Reviews and verifies all uploaded documents and submits the final request for Vendor Code issuance.

System Security & Data Integrity

The system is built on a highly segregated architecture to protect UTP and user data.

Segregated Access

Administrators and customers use distinct entry points, ensuring private admin functions are inaccessible to the public user base.

Face Verification

Manual identity check compares face capture by admin against IC picture data to prevent identity fraud during registration.

Secure Data Handling

All sensitive information is processed using Prepared Statements to prevent SQL injection, maintaining data integrity.
